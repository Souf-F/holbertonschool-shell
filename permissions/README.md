0-iam_betty	Change l'utilisateur actuel pour devenir l'utilisateur betty.

1-who_am_i affiche les identifiants réels et effectifs de l'utilisateur actuel.

2-group Affiche tous les groupes auxquels appartient l'utilisateur actuel.

3-new_owner	Change le propriétaire d'un fichier spécifique.

4-empty	Crée un fichier vide pour préparer la mise en place de droits.

5-execute Ajoute le droit d'exécution au propriétaire du fichier.

6-multiple_permissions Ajoute plusieurs droits en une fois comme la lecture et l'exécution pour le groupe.

7-everybody	Donne le droit d'exécution à tout le monde sur le fichier.

8-James_Bond Supprime tous les droits pour le propriétaire et le groupe mais donne tout aux autres.

9-John_Stack Définit des permissions précises en utilisant le mode numérique.

10-mirror_permissions Copie les permissions d'un fichier source sur un autre fichier.

11-directories_permissions Modifie les permissions de tous les sous-répertoires et fichiers de manière récursive.

12-directory_permissions Crée un nouveau répertoire avec des permissions spécifiques dès sa création.

13-change_group	Change le groupe propriétaire d'un fichier.
