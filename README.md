# Holberton School - Shell

## Description

Ce repository contient tous mes projets sur le shell Bash réalisés à Holberton School.
Chaque dossier correspond à un concept fondamental de l'utilisation du terminal et des scripts shell.

---

## Contenu

| Dossier | Description |
|---|---|
| `basics` | Commandes de base du shell : navigation, fichiers, répertoires |
| `permissions` | Gestion des permissions fichiers avec `chmod`, `chown`, `chgrp` |
| `io_redirections_and_filters` | Redirections `>`, `>>`, `|`, filtres `grep`, `sort`, `uniq` |
| `init_files_variables_and_expansions` | Variables d'environnement, fichiers d'initialisation, expansions shell |

---

## Compétences acquises

- Navigation et manipulation de fichiers dans le terminal
- Gestion des droits et permissions sur les fichiers
- Redirection des entrées/sorties et utilisation des pipes
- Variables shell et d'environnement
- Scripts Bash de base
