## 📝 Liste des Scripts et Fonctions

| Fichier | Description |
| :--- | :--- |
| `0-alias` | Crée un alias personnalisé pour simplifier une commande complexe. |
| `1-hello_you` | Affiche un message de salutation incluant le nom de l'utilisateur actuel. |
| `2-path` | Ajoute le répertoire `/action` à la fin de la variable d'environnement `PATH`. |
| `3-paths` | Compte le nombre de répertoires listés dans la variable `PATH`. |
| `4-global_variables` | Liste toutes les variables d'environnement du système en utilisant `printenv`. |
| `5-local_variables` | Liste toutes les variables shell, les variables locales et les fonctions via la commande `set`. |
| `6-create_local_variable` | Crée une nouvelle variable locale nommée `BEST` avec la valeur `School`. |
| `7-create_global_variable` | Crée une variable d'environnement (globale) exportée. |
| `8-true_knowledge` | Effectue un calcul arithmétique (addition) et affiche le résultat. |
| `9-divide_and_rule` | Réalise une division arithmétique à partir de variables données. |
| `10-love_exponent_breath` | Calcule une puissance (exposant) basée sur deux nombres. |
| `11-binary_to_decimal` | Convertit un nombre binaire (base 2) en nombre décimal (base 10). |
| `12-combinations` | Affiche toutes les combinaisons possibles de deux chiffres. |
| `13-print_float` | Affiche un nombre flottant avec une précision spécifique (formatage de nombre). |
| `14-decimal_to_hexadecimal` | Convertit un nombre décimal en sa valeur hexadécimale (base 16). |
